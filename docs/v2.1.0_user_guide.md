# RiskBands v2.1.0 User Guide

RiskBands v2.1.0 keeps the same fit/transform workflow. The preferred class name is now `RiskBands`; `Binner` remains compatible.

## Imports

Recommended:

```python
from riskbands import RiskBands

binner = RiskBands(...)
```

Short alias:

```python
from riskbands import RiskBands as rb

binner = rb(...)
```

Package alias:

```python
import riskbands as rb

binner = rb.RiskBands(...)
```

Compatibility:

```python
from riskbands import Binner

binner = Binner(...)
```

Do not use `import RiskBands as rb`; v2.1.0 does not add a capitalized package or callable module.

## Pandas

```python
from riskbands import RiskBands

binner = RiskBands(min_n_bins=3)

binner.fit(df_train, target="default_12m", validate=True)

df_binned = binner.transform(df_oot, validate=True)
```

`min_n_bins` is a soft quality rule. If good bins cannot reach the requested minimum, RiskBands keeps the valid binning and records status metadata instead of creating artificial cuts.

## PySpark

PySpark is optional:

```bash
pip install "riskbands[spark]"
```

```python
from riskbands import RiskBands

binner = RiskBands(
    min_n_bins=3,
    sample_size=50_000,
)

binner.fit(spark_train, target="default_12m", validate=True)

spark_binned = binner.transform(spark_oot, validate=True)
```

Spark fit uses controlled sampling, converts that sample to pandas, then uses the current pandas statistical engine. Spark transform preserves a Spark DataFrame and uses native Spark expressions, not Python UDFs. Spark validation builds aggregated profiles in Spark and collects only the small variable/bin profile result.

`validate=True` may execute extra profile calculations. `fit(validate=True)` writes `fit_validation_report_`; `transform(validate=True)` writes `transform_validation_report_` and leaves the fit report available. Without a target column in transform data, RiskBands still applies bins and records that event-rate validation was skipped.

## Bundle

```python
from riskbands.reporting import load_bundle

binner.export_bundle("riskbands_bundle")

bundle = load_bundle("riskbands_bundle")
reference_profile = bundle["reference_profile"]
```

The v2.1.0 bundle stores schema/version metadata, binnings, fit/source/reference profiles, separate fit/transform validation reports, sampling metadata, backend metadata, `min_n_bins` metadata, validation settings, and data schema when those are available.

The bundle loader restores validation metadata for audit and future validation workflows. It does not promise a full distributed Spark fit backend or a reconstructed callable estimator from only the bundle.
