# RiskBands 2.1.0

Type: compatible minor release

Status: prepared for v2.1.0 publication.

## Highlights

- Adds `RiskBands` as the preferred public name while keeping `Binner` compatible.
- Adds `min_n_bins` as a soft quality rule that records status instead of forcing artificial cuts.
- Adds `sample_size` for controlled PySpark fit sampling.
- Detects pandas and PySpark inputs automatically in `fit` and `transform`.
- Preserves dataframe type: pandas returns pandas, PySpark returns PySpark.
- Adds `fit(validate=True)` and `transform(validate=True)` validation profiles with separate fit and transform reports.
- Persists fit/source/reference/application profiles and separate validation reports in v2.1.0 bundles.
- Keeps PySpark optional through the `spark` extra.

## Compatibility

- Existing `from riskbands import Binner` code continues to work.
- Base installation does not install PySpark.
- Bundles without v2.1.0 profile fields continue to load through the compatibility loader.

## Implementation Notes

- PySpark fit uses controlled sampling, converts that sample to pandas, then uses the existing statistical engine.
- PySpark transform and validation profiles use native Spark expressions and aggregated profiles; full transformed/source DataFrames are not collected for validation.
- This release does not implement a full distributed Spark fitting backend.

## Required Validation Before Publication

- `python -m pytest`
- `python -m pytest -m spark` in an environment with PySpark
- `python -m build`
- `python -m twine check dist/*`
- import smoke test for `RiskBands` and `Binner`

PyPI/TestPyPI publication, tag creation, and push are manual release steps outside this note.
