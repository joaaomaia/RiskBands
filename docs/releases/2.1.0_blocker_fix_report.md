## Spark Validation Strategy

Spark validation applies fitted binning rules with Spark column expressions, groups by variable/bin with the target in the same DataFrame, and collects only guarded aggregate profile rows. A guard checks profile row count with `limit(max + 1).count()` before `profile_sdf.toPandas()`.

Remaining Spark `toPandas()` calls in `riskbands/binning_engine.py` are intentional:

- `sampled_spark.toPandas()`: controlled fit sample, bounded by `sample_size`.
- `selected_spark.limit(1).toPandas()`: one-row fallback if random sampling returns empty.
- `profile_sdf.toPandas()`: guarded aggregate profile only, proportional to variables x bins.

The Spark regression suite includes a real Spark test for collision-safe temporary names when user data already contains `__riskbands_bin_label` and `__riskbands_target`, and a guard that fails if validation tries to collect a full Spark DataFrame.
